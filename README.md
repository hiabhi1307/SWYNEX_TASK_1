# SWYNEX Task 1 – Data Cleaning & Preparation

## Objective
Clean and prepare a retail sales dataset for further analysis.

## Data Cleaning Performed
- Checked missing/null values.
- Handled the missing value in the Description column.
- Verified and corrected data types.
- Checked and removed duplicate records.
- Checked negative Quantity values and retained them as they may represent returns/cancellations.
- Verified UnitPrice as a decimal number.
- Checked StockCode and Country values.
- Prepared the cleaned dataset for analysis.

## Tools Used
- Microsoft Excel
- Power Query

## Output
A cleaned retail sales dataset ready for further analysis and dashboard creation.# SWYNEX Task 1 – Data Cleaning & Preparation
